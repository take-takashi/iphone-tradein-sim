# iPhone買い替えコストシミュレーター

GitHub Pagesで動く、日本向けiPhone買い替え費用の静的シミュレーターです。将来価格・下取り額・修理費は予測値ではなく、利用者が編集できる仮定として扱います。未検証の価格表や公開Trade In履歴は実績データとして含めていません。

## ローカルで実行

ビルド不要です。リポジトリのルートで静的サーバーを起動してください。

```sh
python3 -m http.server 8000
```

`http://localhost:8000/` を開きます。入力はブラウザーのローカルストレージに保存されます。

## テスト

```sh
node --test
```

## GitHub Pages

リポジトリ設定の Pages で対象ブランチ／ルートを公開してください。HTML・CSS・JSの参照は相対パスなので、プロジェクトサイトのサブパスでも動作します。ビルド工程はありません。
